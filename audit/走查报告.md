# WeaveClip (CutPilot) 产品走查报告

- **走查日期**：2026-09-18
- **走查版本**：`main @ 6490eb8`
- **走查环境**：前端 Vite 6.4.3 @ :3000，后端 Go/Gin Mock 模式 @ :18081
- **走查范围**：首页 → 登录/注册 → 项目列表 → 创建向导（上传→分析→描述）→ 编辑器（左侧工具栏 / 媒体面板 / 播放器 / 时间轴 / 右侧检查器 / 顶部栏）→ 边界情况
- **截图**：`screenshots/` 目录共 26 张

---

## 一、总体结论

项目处于 **Phase 0（产品骨架 + Mock 数据）**，UI 视觉完成度不错，Morandi 风格统一，路由表完整。但**交互完成度极低**：

- 编辑器左侧 7 个工具栏图标中，只有"媒体"有内容，其余 6 个点击后面板完全不切换；
- 右侧检查器 7 个 tab（调色/滤镜/调整/效果/字幕/速度）全部无响应；
- 首页顶部导航 5 项中 3 项（社区/教程/价格）无响应，侧边栏 4 项全部无响应；
- 编辑器刷新一次就进入"加载失败"死态，无法恢复；
- 核心 P0 引导路径（演示账号）在 Mock 后端不可用。

**新用户完成"看到主界面"的概率很低**：按 UI 引导点"填入演示账号 → 登录"会直接报"邮箱或密码不正确"，必须知道"先注册再登录"。

## 二、P0 阻塞级问题

### P0-1. 演示账号登录失败（引导陷阱）

**截图**：`02_login.png`、`03_login_fail.png`

**现象**：登录页"填入演示账号"按钮填入 `demo@weaveclip.dev / demo1234`，点登录报"邮箱或密码不正确"。

**根因**：`server/internal/service/mock_user_repo.go` 中 `MockUserRepo.users` 初始化为空切片，未 seed 演示用户；前端 `services/authService.ts` 里的 `mockAccount` 只在 `VITE_API_MODE=mock` 时生效，而 dev 环境没设这个变量，走的是真实 API。

**建议**：Mock 后端启动时 seed demo 用户；或前端默认开 mock 模式。

---

### P0-2. 编辑器刷新后进入"加载失败"死态

**截图**：`19_editor_error_state.png`

**现象**：在编辑器页面刷新后，中央区域显示"加载编辑器数据失败 / 返回"，且左侧项目名变成占位符"项目名称"。

**根因**：`pages/Editor/[projectId]/index.tsx` 里 project query 在 token 失效或 API 401 时进入 error 分支，Mock 模式下也没兜底；刷新后 token 未持久化或 401 重试失败。

**影响**：用户一旦刷新就丢失工作区，必须手动回项目列表重进。

---

### P0-3. 左侧工具栏 6 个按钮全部无效

**截图**：`18_sidebar_noop.png`

**现象**：编辑器左侧竖排工具栏——录制、内容、AI 工具、文本、品牌、帮助、"我"——点击后左侧面板内容不切换，始终停留在"媒体"面板。

**预期**：每个图标应切换对应面板（录制 → 录屏面板、文本 → 文本模板库等）。

---

### P0-4. 右侧检查器 7 个 tab 全部无效

**截图**：`20_inspector_tabs_noop.png`

**现象**：右侧检查器"调色 / 滤镜 / 滤镜 / 调整 / 效果 / 字幕 / 速度"7 个 tab 点击后，面板内容始终是"请选择一个片段进行查看"，无任何切换。

**附带**：tab 列表里"滤镜"出现了两次（e42 和 e44），疑似文案重复。

---

### P0-5. 首页导航 3 项 + 侧边栏 4 项全部无效

**截图**：`24_nav_noop.png`

**现象**：
- 顶部导航"社区 / 教程 / 价格"点击后 URL 不变，页面无变化；
- 侧边栏"所有项目 / 我的云端 / 团队协作 / 回收站"点击后同样无反应。

**预期**：至少应有路由占位或"开发中"提示。

---

### P0-6. "导出视频"按钮点击无任何反应

**截图**：`16_export_noop.png`

**现象**：编辑器右上角"导出视频"按钮点击后：无弹窗、无 Toast、无网络请求、控制台无新错误。

**预期**：Phase 0 阶段至少弹"功能开发中"提示。

---

### P0-7. 语言切换按钮无效

**截图**：`17_english.png`

**现象**：编辑器和首页的"中"语言切换按钮点击后，页面文本仍全中文。代码里 `LanguageSwitcher` 确实调用了 `i18n.changeLanguage`，但 UI 没重渲染，或 en.json 的 key 未被实际使用。

## 三、P1 明显缺陷

### P1-1. i18n 插值未替换：`{{count}}` 直接显示

**截图**：`09_upload_i18n_bug.png`

**现象**：上传一个文件后，文件列表显示"1 **{{count}}** 个文件"，插值变量未替换。

---

### P1-2. 登录错误信息直接暴露技术细节

**截图**：`28_login_404_error.png`

**现象**：登录表单输入非法邮箱（如 `notanemail`）+ 短密码后提交，页面直接显示 **"Request failed with status code 404"**，没有本地化、没有友好提示。

**附带**：前端未做邮箱格式校验，把校验完全丢给后端；后端对非法输入返回 404（路由未匹配？）而不是 400。

---

### P1-3. 描述页字数统计重复渲染

**截图**：`11_describe.png`、`25_template_describe.png`

**现象**：textarea 下方"0/500"（或"N/500"）在 DOM 里出现两次（snapshot 同时报 `e25` 和 `e27`），视觉上虽然只看到一处，但 DOM 冗余。

---

### P1-4. 从模板卡片进入描述页，点"生成"无反应

**截图**：`26_generate_noop.png`

**现象**：首页点模板卡片（如"电影感"）跳到 `/projects/new/describe?prompt=...`，此时未经过上传步骤，没有 projectId，直接点"生成"按钮无任何反应，没有引导用户先上传素材。

---

### P1-5. 时间轴片段点击无法选中

**截图**：`13_editor_clip_click.png`

**现象**：时间轴上的 `times_square.mp4` 等片段点击后，bu 报"element center is obscured"，片段不高亮，"分割 / 删除片段"按钮始终 disabled。

---

### P1-6. pnpm install 后 Vite 白屏

**截图**：`01_home.png`

**现象**：按 README 用 `pnpm install` 后 `pnpm dev`，页面白屏，root 为空。`/@vite/client` 返回 `text/html` 而非 JS，React Refresh preamble 未执行。

**根因**：pnpm 11 安装后 `node_modules/vite/` 目录不完整（缺 bin/），Vite 内置 HMR 中间件未注册。换 `npm install` 后正常。

**建议**：README 推荐 npm，或修复 pnpm lockfile / 加 `.npmrc`。

---

### P1-7. `pnpm build` 因 TypeScript 版本报错

**现象**：`tsconfig.json(18,5): error TS5101: Option 'baseUrl' is deprecated`。

**建议**：加 `"ignoreDeprecations": "6.0"` 或迁移 paths。

6. 侧边栏 4 个菜单项加 Toast
7. 导出 / 分享按钮接占位 Toast

14. README 推荐 npm 或修 pnpm lockfile
